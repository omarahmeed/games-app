# Games App

A free-to-play games browser built with HTML, CSS, and JavaScript.

## Features
- Browse games by category (MMORPG, Shooter, Sailing, and more)
- Search games by name
- Skeleton loading screen
- Full game details page

## Tech Stack
- HTML5 / CSS3 / JavaScript (ES6+)
- Bootstrap 5
- Free-to-Play Games API
